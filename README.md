# 🧠 Suicide Detection using NLP

A Deep Learning-based web application that detects suicidal ideation from textual input using Natural Language Processing (NLP) and an LSTM neural network. The project provides real-time predictions through an interactive Streamlit interface.

> **Disclaimer:** This project is intended for educational and research purposes only. It is **not** a substitute for professional mental health assessment or crisis intervention.

---

## 🚀 Features

- Deep Learning text classification using TensorFlow/Keras
- Interactive Streamlit web interface
- Automatic text preprocessing
- Real-time prediction
- Confidence score visualization
- Clean and modular project structure
- Ready for deployment

## 🧹 Data Preprocessing

The text undergoes several preprocessing steps before prediction:

- Convert text to lowercase
- Remove URLs
- Remove mentions
- Remove hashtags
- Remove numbers
- Remove punctuation
- Remove extra whitespace
- Tokenization
- Sequence padding
